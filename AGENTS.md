# Workflow

Create a new branch before starting work. Use the `codex/` prefix unless the user specifies another branch name.

Make and validate the changes, then wait for the user's approval before committing, pushing, or creating a PR. If the user has already authorized those actions for the current changes, proceed without asking again.

## Commit messages

Always use Conventional Commits for commit messages and PR titles, such as `feat:`, `fix:`, `docs:`, or `ci:`. Release Please uses these messages to calculate the next version.
